# Журналы испытаний

Папка содержит сохранённые отчёты, конфигурации и измерения стенда. Большие
потоки `.jsonl` хранятся как `.jsonl.gz`; остальные файлы оставлены без изменений.
Это архив фактических испытаний, включая неуспешные пробы, а не список
рекомендованных настроек или паспортных характеристик.

Проверка всех потоков после клонирования:

```powershell
py scripts/archive-logs.py verify
```

Восстановление привычных `.jsonl` для локального анализа:

```powershell
py scripts/archive-logs.py restore
```

Восстановленные файлы игнорируются Git. Новые локальные потоки можно упаковать
командой `py scripts/archive-logs.py create`; перед коммитом проверьте, что в
них нет персональных данных или секретов.
