# Безопасность

Этот проект исходит из того, что ESC управляет реальным силовым устройством.

Минимальные правила перед запуском команд с `--armed`:

- VESC Tool закрыт, чтобы COM-порт не был занят.
- Вал без нагрузки, мотор механически закреплен.
- Есть физическая кнопка или размыкатель питания ESC.
- USB-команда не считается аварийным стопом.
- Начальный предел скорости: `abs(eRPM) <= 1000`.
- При треске, рывках, росте скорости или потере синхронизации питание отключается физически.

Полная запись XML-конфигураций в ESC по UART пока заблокирована архитектурно. Сначала нужно добавить чтение версии firmware и совместимый бинарный serializer конфигурации.
