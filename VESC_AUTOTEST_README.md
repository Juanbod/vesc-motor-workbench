# VESC Autotest: первый безопасный этап

Скрипт подключается к ESC напрямую по USB/UART, читает телеметрию и проводит ступенчатый тест по току. Он **не записывает** конфигурацию во flash и не меняет FOC-профиль: выбранный профиль сначала загружается через VESC Tool вручную. Это намеренное ограничение первой версии.

## Перед запуском

1. Вал без нагрузки, мотор жёстко закреплён.
2. Должна быть физическая кнопка отключения питания ESC. USB не считается аварийным отключением.
3. В VESC Tool загрузить нужный XML-профиль и закрыть программу, чтобы COM-порт был свободен.
4. Установить обычный Python 3.11+ с python.org: установленный на этом ПК Windows Store launcher сейчас не запускается.
5. В PowerShell выполнить `py -m pip install pyserial`.

## Команды

Сначала найти порт:

```powershell
py C:\Users\elkiy\Documents\Codex\2026-08-11\e-d\outputs\vesc_autotest.py ports
```

Проверить связь без движения:

```powershell
py C:\Users\elkiy\Documents\Codex\2026-08-11\e-d\outputs\vesc_autotest.py monitor --port COM5 --seconds 10
```

Первый ступенчатый тест. `--armed` обязателен; без него скрипт не подаст ток.

```powershell
py C:\Users\elkiy\Documents\Codex\2026-08-11\e-d\outputs\vesc_autotest.py test --port COM5 --armed --steps 3,5,8,11 --hold 2 --log C:\Users\elkiy\Documents\Codex\2026-08-11\e-d\outputs\test-04.csv
```

Стандартные программные стопы: 20 А фазного тока, 15 А батарейного, 3000 eRPM и 70 °C MOSFET. Их можно только ужесточать на первых тестах.

## Следующая версия

После успешного `monitor` и одного CSV-лога добавим применение временных лимитов через VESC protocol и автоматическое сравнение HFI-профилей. Полную смену FOC-параметров из XML по UART будем реализовывать только после считывания точной версии прошивки: бинарная структура конфигурации зависит от версии firmware.
