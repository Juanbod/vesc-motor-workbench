# Profiles

Папки для работы с XML-конфигурациями VESC:

- `incoming` - сюда кладутся новые XML.
- `staged` - сюда CLI переносит проверенные наборы конфигураций.
- `applied` - сюда позднее будет записываться история реально примененных наборов.

Имена пар лучше держать одинаковыми с суффиксами:

- `04_hfi_medium_motor.xml`
- `04_hfi_medium_app.xml`
